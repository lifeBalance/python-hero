# Python sample course

Three small array exercises, used to try out koudmankee while it is being built.

Each exercise gives you a statement, a starter file with the function signature, and a set of tests. Write the function, press Run to try it against the example, press Test to run every case.

## What you need

Nothing. The course runs on `python:3.14-slim` in an isolated virtual machine, and `pytest` is installed into it the first time you open the course.

## Sections

- **Warm-up**: Two Sum, Contains Duplicate. Hash maps and sets.
- **Prefix sums**: Running Sum of 1d Array. The idea behind every range-sum problem.
